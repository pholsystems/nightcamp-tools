# NightCamp Tools

Fan-made tools for the Thai MMORPG **NightCamp**, by KhumGameLab. Everything is in one file: `index.html`.

- **Build Sim** (`#sim`): every job's skill tree, stat allocation, leveling order, gear slots, compare two builds, share codes (`NCB1.…`).
- **อุปกรณ์ / Equipment** (`#equip`): 1,347 weapons, 80 armour sets, 80 hats and 28 glasses. Search by item, monster, map, material or ability; filter by job, weapon type, element, level and source; drop chance at your level; craft recipes with where the materials drop; "ใช้ใน Build Sim" sends the item to the simulator.
- **Meta** (`#meta`): per-job overview and stat formulas.

Data was read from test build `game-20261019-1621`. The game is still being updated, so some numbers may change.
Game names and art belong to NightCamp's developers. This is not an official site.
