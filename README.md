# NightCamp Tools

Fan-made tools for the Thai MMORPG **NightCamp**, by KhumGameLab. Everything is in one file: `index.html`.

- **คู่มือ / Guide** (`#guide`): your character at a glance, where to level by map and element, every job, and the game systems worth knowing.
- **อุปกรณ์ / Equipment** (`#equip`): 1,347 weapons, 80 armour sets, 80 hats and 28 glasses. Search by item, monster, map, material or ability; drop chance at your level; craft recipes; send an item to the Build Sim.
- **Build Sim** (`#sim`): every job's skill tree, stats, gear slots, compare two builds, share codes (`NCB1.…`).

Set your job and level once in the top bar and every page follows it.

Based on the NightCamp test build of 19 Oct 2026; numbers may change with patches.
Game names, art and data belong to the Night Camp team. This is a fan site, not an official one.
